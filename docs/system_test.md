# 系统测试文档

> 本文档记录本项目的系统测试用例与测试结果，覆盖任务管理、状态管理、Worker 队列、Agent 工作流、Trace、工具系统六个模块。

## 2. 任务管理

| 编号 | 测试项           | 预期结果                                     | 结果 |
| ---- | ---------------- | -------------------------------------------- | ---- |
| 1    | 创建任务         | 返回 task_id，数据库中有对应的记录           | 通过 |
| 2    | 查询任务         | 返回对应任务；服务重启时还能查询到对应的任务 | 通过 |
| 3    | 查询不存在的任务 | 返回 404                                     | 通过 |

## 3. 状态管理

| 编号 | 测试项           | 预期结果                                    | 结果 |
| ---- | ---------------- | ------------------------------------------- | ---- |
| 1    | 创建任务但未执行 | 任务状态显示 pending                        | 通过 |
| 2    | 任务运行中       | 任务状态显示 running                        | 通过 |
| 3    | 任务完成         | 任务状态显示 completed                      | 通过 |
| 4    | 任务失败         | 任务状态显示 failed，并记录对应的 traceback | 通过 |

## 4. Worker 队列

| 编号 | 测试项        | 预期结果                                | 结果 |
| ---- | ------------- | --------------------------------------- | ---- |
| 1    | 正常入队      | worker 能够正常获取任务并执行           | 通过 |
| 2    | worker 未启动 | queue 积压任务，rq 队列中有待处理的任务 | 通过 |
| 3    | worker 恢复   | queue 自动消费积压任务                  | 通过 |

## 5. Agent 工作流测试

| 编号 | 测试项       | 预期结果                               | 结果 |
| ---- | ------------ | -------------------------------------- | ---- |
| 1    | 读取文件     | -                                      | 通过 |
| 2    | 文件读取异常 | 当读取文件不存在时终止任务             | 通过 |
| 3    | 总结         | output 目录下的文件存在 summarize 内容 | 通过 |
| 4    | 写入文件     | output 目录下存在目标文件              | 通过 |
| 5    | 工具调用异常 | 调用不存在的工具时终止任务             | 通过 |

## 6. Trace 测试

| 编号 | 测试项             | 预期结果                                                      | 结果 |
| ---- | ------------------ | ------------------------------------------------------------- | ---- |
| 1    | Trace 记录执行轨迹 | 查询后能够返回任务的 Trace                                    | 通过 |
| 2    | Trace 持久化       | 数据库中有对应的 Trace 记录，并且服务重启后还能够查询到 Trace | 通过 |
| 3    | Trace 记录异常信息 | Agent 触发文件读取错误，Trace 中能有正常的记录和报错信息      | 通过 |

## 7. 工具系统测试

| 编号 | 测试项           | 预期结果                                                              | 结果 |
| ---- | ---------------- | --------------------------------------------------------------------- | ---- |
| 1    | 发现工具         | 返回所有工具的 schema（name、description、parameters）                | 通过 |
| 2    | 获取工具         | 返回对应的工具（read_file → ReadFileTool）                            | 通过 |
| 3    | 获取不存在的工具 | 返回工具不存在的错误（ValueError: Tool not found:xxx）                | 通过 |
| 4    | 工具调用结果     | 返回 ToolResultSchema 类型，且 success 为 True                        | 通过 |
| 5    | 工具调用结果异常 | 返回 ToolResultSchema 类型，success 为 False，error 为对应的错误信息 | 通过 |
